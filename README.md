# 用户隐私权利请求履约工作台

覆盖访问、更正、删除、撤回同意和限制处理请求的多页面履约工作台。项目使用 Next.js App Router、Chakra UI、Zustand、TanStack Query、tRPC、Zod 和 TypeScript 构建。

## 功能

- 客服登记请求，根据地区、身份核验状态和请求类型生成处理步骤与期限。
- 定位相关系统、分派任务、登记执行证据、合并跨系统结果并记录处理意见。
- 身份材料只保存掩码引用和摘要，不保存材料明文。
- 重复请求、身份材料不足、跨系统结果冲突自动进入复核队列。
- 支持任务开始、完成和阻断，冲突逐项复核，延期必须填写原因。
- 截止时间前关闭必须记录提前关闭理由，未完成任务或存在冲突时服务端拒绝关闭。
- 汇总登记、核验、分派、证据、冲突、延期和关闭审计，导出脱敏处理包。
- 代理授权处置链：受理时冻结代理关系与查看范围快照（basis v1），系统任务只按该快照产出证据；被代理人撤回、授权到期或换人后，未交付材料立即失效并按新快照重算，已发出处理包保留当时依据并进入复核。
- 两窗口并发（授权变更 × 任务完成）按实际到达顺序裁决，后到动作依据最新代理关系重新判断，乐观版本号防止覆盖已生成结果。
- 系统任务按完整批次执行并幂等：写入中断后以相同幂等键从断点续做，重试不重复生成证据和处理包；批次不跨受理依据版本续写。
- 旧数据缺少代理关系时先回填“待确认”，补全授权前禁止推进系统任务和导出处理包。

tRPC 路由使用 Zod 校验操作输入；TanStack Query 管理服务数据；Zustand 管理工作区筛选状态；每次成功操作都会把完整工作区写入浏览器 `localStorage`。所有写操作携带 `expectedRevision` 乐观版本号，后到的过期提交会被服务端拒绝。

## 处置链校验

```bash
npm run check:chain
```

该脚本对受理冻结、范围越权阻断、撤回/到期/换人失效重算、已发包复核、并发裁决、批次幂等续做、乐观锁和旧数据导出门禁做端到端断言。

## 运行

```bash
npm install
npm run dev
```

开发服务地址：`http://localhost:18457`

## 构建

```bash
npm run build
npm run start
```

## 目录

```text
src/
  app/          Next App Router 页面与 tRPC API Handler
  components/   应用外壳、页面头、状态标签、代理授权处置链面板
  features/     总览、请求列表、请求详情、复核、系统、审计
  lib/          Zod Schema、tRPC 客户端、TanStack Query Hooks、本地存储
  server/       tRPC 服务路由
  services/     流程模板、履约规则、代理依据链、任务批次与并发裁决
  stores/       Zustand 工作区状态
  types/        领域类型
scripts/
  chain-check.ts 代理处置链端到端规则断言（npm run check:chain）
```
